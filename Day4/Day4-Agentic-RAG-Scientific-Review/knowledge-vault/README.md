# Knowledge vault

This folder is an [Obsidian](https://obsidian.md) vault documenting the
Agentic RAG Literature Review & Drug-Discovery Intelligence app.

## Opening it

In Obsidian: **File → Open folder as vault** → select this `knowledge-vault/`
folder. No plugins or config required — it's plain Markdown with
`[[wikilinks]]` and `#tags`, which Obsidian resolves natively.

Start at [[Home]].
