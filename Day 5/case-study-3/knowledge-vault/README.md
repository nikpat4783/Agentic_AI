# Knowledge vault

This folder is an [Obsidian](https://obsidian.md) vault documenting the
Carta Healthcare clinical-data-extraction POC.

## Opening it

In Obsidian: **File → Open folder as vault** → select this `knowledge-vault/`
folder. No plugins or config required — it's plain Markdown with
`[[wikilinks]]` and `#tags`, which Obsidian resolves natively. If Obsidian
isn't installed, every page is just readable Markdown.

Start at [[Home]].
